# Developer Project Starter

A practical reference repository for starting JavaScript and Express projects with a consistent workflow.

It contains project setup guidance, reusable starter patterns, and quick-reference material collected during hands-on development and training.

## Who is this for?

This repository is useful for developers and students who want a clear, repeatable starting point for small JavaScript and Express applications.

## Contents

### [JavaScript + Express Project Starter Guide](guides/javascript-express-project-starter.md)

A step-by-step guide covering:

- requirements, scope, and project planning
- Git, environment variables, and folder structure
- Node.js, Express, and frontend setup
- REST APIs, validation, and error handling
- frontend-backend communication and rendering
- testing, security, documentation, and release workflow

### [Express Cheat Sheet](references/express-cheat-sheet.md)

A quick reference for commonly used Express and related JavaScript concepts:

- application setup and middleware
- routes, request data, and responses
- route and query parameters
- HTTP status codes
- array methods, `fetch`, `async`/`await`, and DOM basics

### [Project Checklist](checklists/project-checklist.md)

A compact, reusable checklist for the planning, implementation, and final verification of a project.

## How to use this repository

1. Start with the project checklist to clarify the requirements.
2. Follow the starter guide while setting up the project.
3. Keep the Express cheat sheet open while implementing routes and frontend communication.
4. Return to the checklist before considering the project complete.

The examples use CommonJS and a simple file structure so the underlying workflow remains easy to understand and adapt.
